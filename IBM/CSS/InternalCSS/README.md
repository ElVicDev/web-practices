### **CSS Interno**
> 1.	Crea un nuevo archivo llamado <b>internal-css.html</b>
> 2.    Agrega una etiqueta `<style>` dentro de la sección `<head>` del documento HTML
> 3.    Dentro de la etiqueta `<style>`:
    <ul>
        <li>Estila un elemento `<h2>` con una fuente Verdana, sans-serif y un borde sólido</li>
        <li>Estila los elementos `<ol>` y `<li>` para que los ítems de la lista tengan un tamaño de fuente de 18px y color de texto azul</li>
    </ul>
> 4.    En la sección `<body>` :
    <ul>
        <li>Agrega un elemento `<h2>` con texto de encabezado</li>
        <li>Agrega una lista ordenada `<ol>` con tres ítems `<li>`</li>
    </ul>
> 5.    Guarda el archivo y visualízalo en tu navegador
