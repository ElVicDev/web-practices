### **CSS en Línea**
> 1.	Abre tu editor HTML y crea un nuevo archivo llamado inline-css.html
> 2.    Usa el atributo style dentro de un elemento HTML para aplicar CSS en línea
> 3.    Aplica estilos a un elemento `<h1>` para que el texto sea azul y esté centrado
> 4.    Agrega un elemento `<p>` con un tamaño de fuente de 18px y color de texto verde
> 5.    Guarda el archivo y visualízalo en tu navegador
