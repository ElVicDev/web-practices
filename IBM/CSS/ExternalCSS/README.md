### **CSS Externo**
> 1.	Crea un nuevo archivo llamado <b>external-css.html</b>
> 2.    Crea un archivo CSS separado llamado <b>styles.css</b>
> 3.    En el archivo <b>styles.css</b>:<br>
    <ul>
        <li>Estiliza el elemento `<h3>` con texto verde oscuro y alineación a la izquierda</li>
        <li>Estiliza el elemento `<table>` con un borde negro y un color de fondo azul claro</li>
    </ul>
> 4.    Enlaza el archivo <b>styles.css</b> a <b>external-css.html</b> utilizando la etiqueta `<link>`
> 5.    En la sección `<body>` de <b>external-css.html</b>:
    <ul>
        <li>Agrega un elemento `<h3>` con texto de encabezado</li>
        <li>Agrega un elemento `<table>` con dos filas y dos columnas</li>
    </ul>
> 6.    Guarda ambos archivos y visualiza el archivo <b>external-css.html</b> en tu navegador
