You can use the <#> or <#top> for example, to go to Top of Page or a different section of the page.

You can use the <ol> (ordered list) tag for numbered lists and the <ul> (unordered list) tag for bulleted lists.

Each point within a list will be enclosed by a <li> opening and closing tag, which represents a list item.

This same tag is used for both ordered and unordered lists.

  • The items in this list have no particular order
