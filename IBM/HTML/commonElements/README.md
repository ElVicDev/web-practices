## Ejercicio 3: Juega con JavaScript.
JavaScript hace que una página web sea interactiva. Cuando haces clic en el botón “Deseo”, la página muestra una alerta que dice “Hola, ¿cómo estás?”.<br>
**Nota:**<br>
*Si la alerta no aparece, por favor permite las ventanas emergentes para este sitio web cambiando la configuración de tu navegador*.<br>

1.	En el área de JavaScript, la línea número 2 define el mensaje que se muestra cada vez que se hace clic en el botón “Deseo”.
    *	Reemplaza el mensaje con "Buen Día".
    *	Guarda los cambios.
    *	Haz clic en el botón "Deseo" en el área de vista previa.
    *	Deberías ver una alerta emergente con tu nuevo mensaje.
    *	Prueba con "Hola, como estas". Por cierto, eso es “Hello, how are you doing” en español.
2.	La línea número 5 tiene una función llamada showtime. Muestra la hora actual.
    *	En el área de HTML, tiene la palabra 'Deseo'. Reemplázala con 'Mostrar Hora'.
    *	Reemplaza 'hello()' en la línea número 20 con 'showtime()'.
    *	Guarda los cambios.
    *	En el área de vista previa, ahora verás un botón llamado 'Mostrar Hora'.
    *	Haz clic en él. Un mensaje con la hora actual debería aparecer.
