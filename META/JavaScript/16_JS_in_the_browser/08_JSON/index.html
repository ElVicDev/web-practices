JSON

Realizar las siguientes prácticas utilizando las herramientas para el desarrollador

Si escribo un fragmanto de código JSON en la consola del navegador, no se produce ningún error

JSON es solo un objeto representado en forma de cadena:

'{"greeting":"hello"}'

Para trabajar con JSON, es común convertirlo en un objeto JavaScript.

Es necesario utilizar el objeto JSON global incorporado y su método parse()

const jsonStr = '{"greeting":"hello"}'

JSON.parse(jsonStr)

const aPlainObj = JSON.parse(jsonStr)

Hasta aquí, la cadena JSON está almacenada como un objeto JavaScript normal

aPlainObj.greeting = 'hi'

aPlainObj

También puedo convertir un objeto normal en una cadena JSON con el método stringify()

const data = { firstName: "John", lastName: "Doe", greeting: "Hello", }

JSON.stringify(data)

  • Los objetos de JavaScript pueden contener funciones y las cadenas JSON no pueden.
  • JSON no permite el uso de comentarios de JavaScript
  • Cuando se usa stringify con un objeto de JavaScript que contiene un método, este método será excluido.
