Controlador de eventos

Realizar las siguientes prácticas utilizando las herramientas para el desarrollador

const target = document.querySelector('body')

function handleClick() { console.log('Clicked the body') }

target.addEventListener('click', handleClick)

Pulsa sobre cualquier parte del body y observa la consola.

Una forma alternativa de escuchar los eventos es usando los atributos de eventos HTML

function handleClick2() { console.log('Clicked the h1 (Example Domain)') }

Al hacer click sobre Example Domain, desencadena dos detectores de eventos:

Uno es por haber pulsado sobre el H1 (Example Domain) y el otro es porque H1 esta dentro del body
